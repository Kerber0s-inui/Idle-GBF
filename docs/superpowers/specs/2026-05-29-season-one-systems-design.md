# 第一赛季系统设计

## 范围

这份规格定义 Idle-GBF 第一赛季的完整系统方向，包括 14 到 21 天的赛季节奏、战斗公式、武器和召唤体系、角色被动和羁绊、关卡开放、掉落节奏、高难目标，以及第一批实现顺序。

第一赛季会先打开六属性框架，但重点调校路线是火队打风属性敌人。

## 目标

1. 先建立稳定的战斗和成长骨架，再扩大量内容。
2. 让武器盘围绕 `星印`、`方阵`、`EX` 三个独立体系形成构筑差异。
3. 保留角色、武器、召唤白值价值，但让词条和体系选择成为主要差异。
4. 为 HP、防御、连击、充能、普攻上限、奥义上限等关键效果设置上限。
5. 让高难需要编成、羁绊、生存和奥义频率规划，而不是只堆攻击。
6. 提供一条 14 到 21 天的第一赛季路线，包含开放顺序、掉落层级和实力门槛。

## 已确认方向

- 第一赛季目标游玩时长为 14 到 21 天。
- 主线赠送 6 到 8 名核心角色，保证每个玩家都有基础羁绊组合。
- 抽卡提供横向选择和更强的长期 `星印` 体系。
- 第一赛季总计发放约 150 到 200 抽。
- 100 抽可井，可自选当期角色绑定武器、`星印` 武器或召唤石。
- SSR 率保持偏低，让抽卡过程有期待，但井机制避免长期获取焦虑。
- BOSS 主要掉落 `方阵` 装备和突破素材。
- 主线主要给 `EX` 装备、特殊武器材料和系统开放。
- 素材本主要提供强化、突破、技能素材。
- 战斗保持自动，但高难加入机制检定。
- 六属性有基础 BOSS 和素材框架，第一赛季重点调校火打风。
- 第一赛季不做支援召唤。
- 第一赛季不做属性主召加护。

## 战斗公式

### 白值汇总

角色、武器、召唤都有 `HP / 攻 / 防` 白值。

白值先汇总，再吃词条和加护：

- 角色白值来自当前行动角色。
- 武器盘白值全部相加后，平均分摊给 4 名队伍成员。
- 召唤盘白值全部相加后，平均分摊给 4 名队伍成员。

第一赛季建议公式：

```text
基础攻击 = 角色攻击 + floor(武器盘总攻击 / 4) + floor(召唤盘总攻击 / 4)
基础HP = 角色HP + floor(武器盘总HP / 4) + floor(召唤盘总HP / 4)
基础防御 = 角色防御 + floor(武器盘总防御 / 4) + floor(召唤盘总防御 / 4)
```

武器和召唤白值会随等级提升，但同稀有度武器之间的白值方差控制在约 `±12%`。构筑差异主要来自词条、加护和特殊机制。

### 乘区

第一赛季伤害使用独立乘区：

```text
最终攻击 =
  基础攻击
  * 星印乘区
  * 方阵乘区
  * EX乘区
  * 特殊乘区
```

- `星印` 词条来自抽卡武器和角色绑定武器，只吃 `星印加护`。
- `方阵` 词条来自 BOSS 掉落武器，只吃 `方阵加护`。
- `EX` 词条来自主线、活动和特殊武器，不吃任何加护。
- 角色被动1可以提供简单数值或小机制，不吃召唤加护。
- 羁绊效果进入特殊乘区或机制层，但仍受全局上限限制。

### 第一赛季效果上限

上限应集中在 domain 层，方便未来赛季调参。

| 效果 | 第一赛季上限 |
| --- | ---: |
| HP加成 | `+400%` |
| 防御加成 | `+100%` |
| 连击率展示 | `+75%` |
| 充能效率 | `+50%` |
| 普攻上限 | `+50%` |
| 奥义上限 | `+50%` |
| 奥义伤害 | `+100%` |
| 掉落率 | `+50%` |
| 星印加护 | 最高 `+120%` |
| 方阵加护 | 最高 `+120%` |

如果后续拆成 DA/TA，第一版可设为 `DA +75%`、`TA +50%`。

### 伤害上限命名

统一使用：

- `普攻上限`：普通攻击每 hit 的伤害上限。
- `奥义上限`：奥义伤害上限。

第一赛季建议数值：

```text
普攻基础上限 = 440000 / hit
普攻最终最高上限 = 660000 / hit

奥义基础上限 = 1160000
奥义最终最高上限 = 1740000
```

`普攻上限` 只提高普通攻击每 hit 上限。
`奥义上限` 只提高奥义上限。
第一赛季不做通用 `伤害上限` 主词条。未来如果做稀有效果，也必须分别计入 `普攻上限` 和 `奥义上限` 的总上限。

## 装备体系

### 星印体系

`星印` 是抽卡装备体系。

- 来源：抽卡武器、角色绑定武器、抽卡召唤石。
- 词条例子：`星印攻刃`、`星印守护`、`星印普攻上限`、`星印奥义上限`。
- 加护：只有 `星印加护` 提升这些词条。
- 定位：完整成型后理论最强，但获取和突破更慢。

第一赛季应让玩家通过井稳定获得 1 到 2 个关键 `星印` 组件，但不能轻松完成完整毕业盘。

### 方阵体系

`方阵` 是可刷 BOSS 掉落体系。

- 来源：六属性 BOSS。
- 词条例子：`方阵攻刃`、`方阵守护`、`方阵连击`、`方阵奥义上限`。
- 加护：只有 `方阵加护` 提升这些词条。
- 定位：第一赛季免费主力，成型快，尤其服务火打风路线。

第一赛季中，玩家应能做出一套可用的 3 突、100 级、技能 10 到 15 的 `方阵` 核心盘。

### EX体系

`EX` 是主线和活动插件体系。

- 来源：主线、活动、特殊武器。
- 加护：不吃任何加护。
- 定位：独立乘区插件，`星印` 盘和 `方阵` 盘都想带。

大部分武器盘应携带 1 到 3 把 EX 武器，而不是铺满 EX。

### 主线特殊武器

第一赛季引入 3 把高价值特殊武器，每把唯一装备，同一武器盘只能生效 1 把。

- `誓约武器`：EX攻刃 + 普攻上限；约第4章解锁。
- `羁绊武器`：根据已触发羁绊强化 HP、防御、奥义上限；约第6章解锁。
- `界限武器`：后期高难工具，提供少量上限或机制解法；约第8章解锁。

这些武器通过主线和高阶素材升级，应像 GBF 的法武、巴武、U武一样长期有价值，但不依赖抽卡。

### 推荐武器盘形态

- 方阵成型盘：5 到 6 把 `方阵`，1 到 2 把 EX，1 把主线特殊武器，0 到 2 把 `星印` 插件。
- 星印进阶盘：4 到 5 把 `星印`，1 到 2 把 `方阵` 或 EX 插件，1 把主线特殊武器。
- 高难策略盘：可能牺牲攻击，改带 HP、防御、充能、羁绊或机制对策武器。

## 召唤石

第一赛季只做两类主加护：

- `星印加护`：提升 `星印` 武器词条效果。
- `方阵加护`：提升 `方阵` 武器词条效果。

第一赛季不做属性主召加护，也不做支援召唤。

副召唤只提供白值和少量功能效果，不参与主加护体系。

第一赛季加护成长建议：

- 早期主加护：`+50%` 到 `+80%`
- 第一赛季高级主加护：最高 `+120%`

## 角色与羁绊

### 被动1

被动1在第一次突破解锁。

它负责定义角色基础定位：

- 攻击手：自身攻击、奥义伤害、普攻上限、连击率。
- 防御手：全队 HP、防御、受伤充能。
- 奥义手：充能效率、奥义上限、开局充能。
- 资源手：掉落率、素材获取、扫荡收益。

被动1可以是自身效果，也可以是小幅全队效果，但不应单独决定整个体系。

### 被动2与羁绊标签

被动2在第三次突破且达到 100 级后解锁。

被动2提供一个或多个羁绊标签。强效果来自队伍组合，而不是单张角色卡。

第一赛季先做 4 类羁绊：

| 羁绊 | 触发条件 | 效果 | 主要用途 |
| --- | --- | --- | --- |
| `赤轨小队` | 至少 3 名 `赤轨` 角色 | 充能效率 `+20%`，奥义上限 `+15%` | 爆发和危险血量段 |
| `炉心防线` | 至少 2 名 `炉心` 角色 + 1 名防御定位角色 | HP `+30%`，防御 `+25%`，首次全体特动伤害 `-20%` | 生存检查 |
| `星回协议` | 至少 2 名 `星回` 角色 + 队伍平均奥义上限达到 `+20%` | 奥义伤害 `+20%`，奥义上限 `+20%`，防御 `-10%` | 高风险爆发 |
| `灰烬拾荒` | 至少 2 名 `灰烬` 角色 | 掉落率 `+15%`，扫荡材料数量 `+10%`；高难中无效或削弱 | 日常刷本 |

羁绊效果仍受全局上限限制。

### 羁绊UI

编队和角色选择 UI 需要展示羁绊信息：

- 角色卡片和选择列表显示羁绊标签。
- 被动2尚未解锁时，羁绊标签灰显并提示解锁条件。
- 编队下方显示已触发羁绊。
- 编队下方也显示接近触发的羁绊，例如 `2/3，还需要 1 名防御角色`。
- BOSS 详情可显示机制标签，例如 `生存`、`奥义频率`，但不直接给标准答案。

## 第一赛季路线

### 主线

第一赛季建议做 8 章，每章 3 个主线关卡，共 24 个主线本。

主线不支持扫荡。主线负责开放系统、赠送核心角色、给 EX 武器和特殊武器材料。

建议开放顺序：

| 章节 | 开放内容 |
| --- | --- |
| 第1章 | 基础战斗、远征、首批 4 名火角色、基础 EX 武器 |
| 第2章 | BOSS 本、素材本、`方阵` 系统 |
| 第3章 | 第 5 名火角色、稳定角色突破素材来源 |
| 第4章 | 召唤强化、`誓约武器` |
| 第5章 | 第 6 名火角色、六属性初级 BOSS |
| 第6章 | 方阵中级、`羁绊武器` |
| 第7章 | 方阵高级、井商店可视化、武器盘优化压力 |
| 第8章 | 风属性极难 BOSS、第一赛季高难、`界限武器` 第一阶段 |

### BOSS本

六属性都开放 BOSS，但火打风是第一赛季完整调校路线。

每个属性先做 4 个难度：

- 初级：第2章后开放，目标 40 到 60 级队伍。
- 中级：第4章后开放，目标 60 到 80 级队伍。
- 高级：第6章后开放，目标 80 到 100 级队伍。
- 极难：第8章后开放，目标 100 级队伍、3突核心盘和初步羁绊。

BOSS 本掉落 `方阵` 武器、`方阵` 召唤和突破素材。

### 素材本

每个属性有 3 个素材层级：

- 训练场：角色经验、低级角色突破素材。
- 工坊：武器经验、召唤经验、技能素材。
- 遗迹：高级突破素材、特殊主线武器材料。

素材本不掉核心 `方阵` 武器。

### 高难本

第一赛季重点做两个风属性高难。

#### 风高难 I：生存检查

- 50% 血量触发全体大伤害。
- 纯攻击盘容易倒人。
- 解法包括 `炉心防线`、HP/防御词条、`方阵守护`、`羁绊武器`。

#### 风高难 II：奥义频率检查

- 75% 和 35% 血量进入风压状态。
- 如果玩家在短回合窗口内没有打出足够奥义伤害，BOSS 获得防御或连续特动。
- 解法包括 `赤轨小队`、充能效率、连击率、奥义上限、`界限武器`。

后续高难可以预留护盾层数、爆发倒计时、抗性切换、压血惩罚、刷本羁绊削弱等机制。

## 掉落与节奏

### BOSS节奏

| 难度 | 稳定期 | 主要掉落 | 预期进度 |
| --- | --- | --- | --- |
| 初级 | 第2到4天 | 低级突破素材、武器碎片、低概率整武器 | 核心角色 1突，2到3把 `方阵` |
| 中级 | 第5到8天 | 中级突破素材、`方阵` 武器、`方阵` 召唤碎片、少量技能素材 | 4到5把 2突 `方阵`，角色接近80级 |
| 高级 | 第9到13天 | 高级突破素材、更高整武器概率、召唤、特殊武器材料 | 核心盘进入3突，角色100级，技能10到15 |
| 极难 | 第14到21天 | 大量高级素材、特殊武器材料、高难兑换币 | 编成检定和后期优化 |

### 素材本节奏

- 训练场服务第1到7天的角色升级。
- 工坊服务第4到14天的武器、召唤和技能成长。
- 遗迹服务第8章后的高难准备。

低级素材不能无限自由兑换高级素材。可以做有限兑换，但不能让初级本替代高级和极难进度。

### 抽卡资源

第一赛季总计约 150 到 200 抽：

- 主线首通：50 到 60 抽。
- BOSS/素材首通：35 到 45 抽。
- 赛季目标：50 到 70 抽。
- 日志/每日累计：20 到 30 抽。

100 抽可井。

## 实力门槛

| 时间 | 预期状态 |
| --- | --- |
| 第3天 | 能过初级 BOSS，但不应稳定刷中级 |
| 第7天 | 稳定刷中级，可以尝试高级但不稳定 |
| 第12天 | 稳定刷高级，极难通常仍然打不过 |
| 第16天 | 合理编成可过极难，纯攻击盘可能被机制卡住 |
| 第21天 | 优化武器盘、羁绊和特殊武器后，可挑战高难 I/II |

## 防止无脑膨胀

- 白值稳定成长，但主要成长来自体系乘区和词条组合。
- `普攻上限` 和 `奥义上限` 防止攻击堆叠跳过内容。
- HP、防御、连击、充能、掉落率都有上限。
- BOSS 机制要求生存、奥义频率、羁绊或防御规划。
- `星印` 长期更强，但获取和突破更慢。
- `方阵` 可刷且成型快，但完整强度略低于毕业 `星印`。
- 刷本羁绊在高难中无效或削弱。

## 第一批实现顺序

### 第一批：可见的强化和编成反馈

- 武器和召唤卡片的星星展示同步角色卡片。
- 删除武器和召唤卡片上的 `突破 N` 文本。
- 升级弹窗除了等级预览，再增加 3 行数值预览。
- 升级预览展示武器/召唤的 `HP / 攻 / 防` 白值变化。
- 角色选择列表和编成角色卡显示羁绊标签。
- 编队下方显示当前已触发和接近触发的羁绊。

### 第二批：公式基础

- 集中定义效果上限。
- 分离并统一命名 `普攻上限` 和 `奥义上限`。
- 角色、武器、召唤白值先汇总再进入公式。
- 应用带上限的 `星印`、`方阵`、`EX` 乘区。
- 移除第一赛季属性主召加护假设。
- 为上限和白值汇总补测试。

### 第三批：内容分类

- 武器增加体系字段：`星印`、`方阵`、`EX`、主线特殊武器。
- 召唤增加加护字段：`星印加护`、`方阵加护`。
- 角色增加羁绊标签。
- 增加第一批 6 到 8 名火路线核心角色。
- 增加第一批 `方阵`、`EX`、特殊、`星印` 装备定义。

### 第四批：关卡和经济扩展

- 增加 8 章主线结构。
- 增加六属性初级/中级/高级/极难 BOSS 框架。
- 完整调校风属性 BOSS 路线。
- 增加素材本层级。
- 增加掉落层级和第一赛季抽卡资源。
- 增加 100 抽井计数和自选流程。

### 第五批：高难

- 增加风高难 I 生存机制。
- 增加风高难 II 奥义频率机制。
- BOSS UI 显示机制标签。
- 为高难机制结果补测试。

## 调参备注

这份文档中的数值是第一赛季起始目标。第二批和第四批实现后，需要用战斗模拟测试继续调参。已固定的重点是系统边界、命名和玩家路线：

- `星印` 是抽卡体系。
- `方阵` 是可刷 BOSS 体系。
- `EX` 是不吃加护的插件体系。
- 第一赛季没有支援召唤。
- 第一赛季没有属性主召加护。
- 第一赛季高难必须要求编成策略，而不是只要求更高攻击。
